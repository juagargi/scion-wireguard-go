Inside this folder, run `docker compose up` to start the prometheus and grafana docker container.
The `prometheus.yml` configuration assumes that the dockerized tiny topology is being used.
The grafana web interface can be visited by opening `http://localhost:3000` in the web browser with username = admin, password = admin.
While the prometheus and grafana docker container are running, it will automatically collect the metrics generated by the integration test and visualize them in grafana.
